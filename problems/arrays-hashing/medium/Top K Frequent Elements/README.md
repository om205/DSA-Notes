# Top K Frequent Elements

- Difficulty: Medium
- Topic: Array, Hash Map, Sorting, Heap (Priority Queue), Bucket Sort
- Platform: LeetCode
- Link: https://leetcode.com/problems/top-k-frequent-elements/

---

## Problem Statement

Given an integer array nums and an integer k, return the k most frequent elements. You may return the answer in any order. The test cases are generated such that the answer is always unique. It is guaranteed that there will be at least k unique elements in the array.

---

## Examples

### Example 1

```txt
Input: nums = [1,1,1,2,2,3], k = 2

Output: [1,2]
```
### Example 2

```txt
Input: nums = [1], k = 1

Output: [1]
```
---

## Constraints

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `k is in the range [1, the number of unique elements in the array].`
- `It is guaranteed that the answer is unique.`
